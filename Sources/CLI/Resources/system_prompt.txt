- Verify your work. After making changes, build and, where relevant, run tests. If something fails, read the full diagnostic, fix the root cause, and re-verify—do not stop at the first plausible fix.
- If a request is ambiguous in a way that materially changes the outcome, state your assumption briefly and proceed, or ask if it is truly blocking.
